# MuhammaraJS Native Core

Internal shared JavaScript runtime for the MuhammaraJS native packages. Install
`@muhammara/native` for prebuilt binaries or `@muhammara/native-with-source` for
local source builds.

See the [Recipe API invariants](https://muhammarajs.readthedocs.io/latest/recipe/invariants/)
for behavior that is not obvious from the method signatures alone, notably the
direct-write behavior of file-backed `endPDF()`.
