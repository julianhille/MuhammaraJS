# MuhammaraJS Native Core

Internal shared JavaScript runtime for the MuhammaraJS native packages. Install
`@muhammara/native` for prebuilt binaries or `@muhammara/native-with-source` for
local source builds.

See [Recipe API Invariants](docs/recipe/invariants.md) for behavior that
isn't obvious from the method signatures alone - notably the direct-write
behavior of file-backed `endPDF()`.
